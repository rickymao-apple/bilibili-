# B 站视频转文字

把网课或讲解视频整理成可以复制、下载和打印的文字稿。粘贴一个 B 站视频链接，优先提取可读取的字幕；没有字幕时，可选择在电脑上运行 FunASR 语音识别。无需购买语音识别 API。

## 当前功能

- 支持普通 BV/av 视频、BV 号、b23.tv 短链，以及包含单个链接的分享文字。
- 支持分 P 链接，例如 `?p=2`；每次只处理指定的一集，不会自动下载整套合集。
- 优先使用中文人工字幕，其次中文自动字幕，再尝试其他语言字幕；弹幕不会当作字幕。
- 直接解析 yt-dlp 提供的 SRT 字幕，兼容 VTT、B 站 JSON 和 JSON3。提取字幕不会触发视频下载。
- 进度、错误提示与文字稿分开显示，正文可以一键复制。
- 导出 UTF-8 TXT 和 Markdown；有真实时间轴时另提供 SRT，不会为无时间轴的识别结果编造字幕时间。
- 每个浏览器会话保留最近 5 条结果，便于切换、复制和重新下载。

## 快速开始：只提取字幕

推荐 Python 3.11 或 3.12。在项目目录运行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows 激活环境时使用 `.venv\Scripts\activate`。启动后访问 `http://127.0.0.1:7860`，粘贴视频链接并点击“开始转写”。字幕模式不需要安装 FFmpeg、PyTorch 或 FunASR，也不会下载语音模型。

如果没有可读字幕，界面会提示安装可选语音识别依赖；也可以取消勾选“没有可读字幕时，使用本地语音识别”，只运行字幕模式。

## 可选：启用本地语音识别

先安装 [FFmpeg](https://ffmpeg.org/download.html)，确认终端中能运行 `ffmpeg -version`，再安装：

```sh
python -m pip install -r requirements-asr.txt
python main.py
```

首次识别会从模型仓库下载普通话 Paraformer、VAD 与标点模型，需要网络、内存和磁盘空间，具体耗时取决于设备与视频长度。后续使用会复用本地缓存。无需付费 API，但模型下载与本地计算会消耗资源。

音频路径只下载音轨，再直接转换成单声道 16 kHz WAV，不经过有损 MP3 中间文件。模型加载与推理使用同一把锁，避免并发加载多份模型或交叉调用推理。默认 CPU 推理，不会假定电脑有 CUDA。

语音识别每次限制为两小时、音频下载上限 300 MB。需要处理长课程时，请选择较短的分 P。遇到无声、背景音乐、口音或专业术语时，结果可能不准确，需要核对原视频。

## 文件、历史与访问范围

- 默认只监听本机，不创建公网分享链接。
- 音频使用每次任务独立的临时目录，成功、失败或生成器关闭时都会清理；最终结果返回前已删除媒体临时文件。
- 每条结果使用独立导出目录。会话历史只保存最近 5 条，淘汰记录会清理对应导出；Gradio 下载缓存与会话状态约保留一小时，浏览器关闭或刷新也可能使历史失效。需要长期保留的文字稿请及时下载。
- 链接逐级校验主机与短链跳转，不接受把 `bilibili.com` 塞在其他网站地址里的伪造链接。
- 本版不读取浏览器登录、Cookies 或账号密码，不绕过会员、登录、地区或平台风控限制。请处理你有权访问和使用的内容。

可通过 `python main.py --port 7861` 更换端口。`--host` 可调整监听地址，但该工具面向本机使用；如要多人访问，应另行配置认证、网络访问限制和资源配额。

## 常见问题

**视频有字幕，却提示没有可读字幕？**

视频画面中的硬字幕不一定有可下载的字幕轨道；部分 B 站字幕还要求登录。可以启用本地语音识别。也可先更新提取器：

```sh
python -m pip install --upgrade yt-dlp
```

**提示 B 站暂时拒绝访问？**

常见于平台限频、风控或网络环境限制。稍后重试，或更换可以公开播放的视频。本工具不会尝试绕过验证。

**没有 SRT 下载项？**

只有原字幕或模型返回完整、有效的时间轴时才生成 SRT。纯文本识别仍可导出 TXT 和 Markdown。

**如何生成思维导图？**

本版提供 Markdown 文字稿，便于后续整理为笔记或交给你选择的工具处理；目前没有自动生成思维导图的功能，也不会偷偷调用外部 AI API。

## 开发验证

```sh
python -m unittest discover -s tests -v
python -m pip check
```

离线测试使用模拟视频信息、字幕和模型，覆盖链接与跳转校验、字幕格式和优先级、分 P、无字幕回退、媒体清理、模型并发、导出与会话历史。GitHub Actions 对 Python 3.11、3.12、3.13 运行检查。测试不会下载真实视频或大型语音模型。

核心文件：`transcriber.py` 处理视频与转写，`exports.py` 处理导出和历史，`main.py` 提供 Gradio 界面。基础依赖与语音识别依赖分开维护。

实现参考：[yt-dlp 的 B 站提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)、[FunASR 官方示例](https://github.com/modelscope/FunASR)、[Gradio 文档](https://www.gradio.app/docs)。
